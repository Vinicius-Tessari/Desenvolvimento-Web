# Exercício - Sistema de Notas

Crie uma página HTML com JavaScript que receba **3 notas** e calcule a **média** de um aluno.

A página deve ter:
- 3 campos para digitar as notas;
- 1 botão para calcular;
- 1 espaço no HTML para mostrar o resultado.

## Regras

- **Média maior ou igual a 7:** Aprovado.
- **Média maior ou igual a 5 e menor que 7:** Recuperação.
- **Média menor que 5:** Reprovado.

Use `try`, `catch` e `throw` para tratar erros:
- Os campos não podem ficar vazios.
- As notas devem estar entre 0 e 10.

Mostre a média e a situação do aluno no HTML. Se houver erro, mostre a mensagem na página.

**Arquivos para entregar:** `index.html` e `script.js`.
